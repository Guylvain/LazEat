# Coffre Nutrition

Système personnel de planification alimentaire. Coffre Obsidian servant de source
de vérité pour les recettes et le contexte projet.

## Structure

```
00-Contexte/     Documents de cadrage et spécifications
01-Recettes/     31 recettes au format validé + gabarit + inventaire
02-Ingredients/  Référentiel canonique d'ingrédients (à construire)
03-Semaines/     Plannings hebdomadaires
04-Suivi/        Courses, placards, historique
assets/          Photos de recettes
```

## État d'avancement

- [x] Phase 0 — Contexte, gabarit, 31 recettes
- [ ] Phase 0 — Référentiel d'ingrédients
- [ ] Phase 1 — Planning et liste de courses manuels (3 semaines de vécu)
- [ ] Phase 2 — PWA, matching, écran de bilan
- [ ] Phase 3 — Placards, stock, magasins
- [ ] Phase 4 — Portions stockées
- [ ] Phase 5 — Scoring, gaspillage, budget

## Règles de travail

Une seule session agentique à la fois sur ce dossier. Commiter avant et après
chaque session pour pouvoir revenir en arrière.

## Objectifs biologiques (bilan du 23/07/2026)

| Cible | Constat | Levier |
|---|---|---|
| Remonter les folates | 3,30 ng/ml (norme > 3,89) | Légumineuses, petits pois, agrumes |
| Baisser les triglycérides | 1,50 g/L | Moins de sucres rapides, plus d'oméga-3 |
| Couvrir la dépense | 5 séances/semaine, repas sautés | Régularité, densité glucidique |

Contrôle prévu : redoser folates et triglycérides à 3-4 mois.
